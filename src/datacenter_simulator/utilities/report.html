Model and data boundaries

__CENTER__. Reference inputs are synthetic and equipment parameters are illustrative. Physical device dimensions drive the hall geometry; server faces, cable routes and CDU placement are illustrative. The thermal model is lumped, with no CFD or hotspot prediction. Power and cooling shortfalls are reported without automatic workload shedding. PUE describes requested facility demand before generation.

Inspect and extend

The Python package separates devices, simulation methods, generation connectors and plotting utilities. External generation profiles must have matching timezone-aware interval timestamps. All charts work offline.
