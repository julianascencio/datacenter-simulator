Data Center Simulator
=============================

Build a data center from devices, then connect its electrical, communication,
cooling and generation models. This Python research prototype emphasizes
direct-current distribution and transparent energy accounting.

.. raw:: html

   <p><a class="btn btn-primary" href="_static/lab/reference-lab.html">Open the interactive 2D / 3D simulation lab →</a></p>

The offline lab includes an orbitable equipment hall, a dimensioned floor plan,
DC single-line and communication diagrams, cooling flows, generation dispatch
and an HVAC comparison. All reference data are synthetic.
